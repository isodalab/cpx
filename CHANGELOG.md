# Changelog

## 1.0.0 (November 2026)

First release of **CPX — Click Polytempo eXtended**, by IsodaLab, for Windows (VST3), macOS on Apple silicon (VST3 + Audio Unit) and Linux (VST3 + LV2).

- Tempo sources: HOST (the host's tempo map, at any ratio, with the host's meter or CPX's own), OWN (CPX's own tempo, locked to the timeline), FREE (CPX's own clock, with START and STOP).
- Sync points on the timeline, shared by groups A to D: CPX at different tempos meet on a downbeat, to the sample. Optional start point; FIT to a whole number of beats or bars.
- Any meter: 1–32 beats on any note value from 1 to 64; groups such as 2+2+3; an accent level per beat (Accent, Medium, Beat, Soft, Off).
- Subdivisions 1–8 with swing; 15 synthesised sounds with a level per accent; output level and pan; input + click or click only.
- Tap tempo on the screen and by MIDI learn (notes, pads, pedals), from the DAW or directly from the computer's MIDI inputs; MIDI start / stop for FREE.
- Polytempo view of every CPX in the project, with the sync points.
- Info tips on hover, which can be turned off in Settings.
